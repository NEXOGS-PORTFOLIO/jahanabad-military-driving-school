Certificate typography
======================

Heading: regular Old English Text MT.
Certificate body labels and filled details: Lobster Regular, matching the supplied
script reference. Filled details and the combined date range start at the left
inset of their dotted rules. Body labels use 11.5 points; details use 12 points.
Serial: Georgia Regular.
Location, issue date and signatures: regular Monotype Corsiva.
Dotted field rules and a shared text baseline keep the body aligned.

Lobster is covered by the bundled Lobster-OFL.txt license. The other active fonts
were copied from installed Windows fonts, and their
embedding flags allow PDF embedding. They are proprietary, not covered by the
OFL licenses. PDFKit embeds font subsets for
consistent preview and download. The deployment packager includes these assets.
Font content and design version changes invalidate cached PDFs.
